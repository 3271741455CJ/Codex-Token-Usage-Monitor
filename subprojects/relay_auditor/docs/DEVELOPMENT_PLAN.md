# 独立质量检测产品实施记录

依据用户批准的《开源模型质量检测项目发展计划》。本次实现软件与离线验证；不进行拆仓、提交、合并、发布，不读取真实凭据，不发起付费采样。主项目运行路径和 VERSION 不变。

## 工作顺序

1. 共享核心：版本化任务套件、确定性评分、四维证据报告、v1 历史兼容、可比较趋势。
2. 实用功能：专用本地配置、可选系统凭据库、恢复后关闭、队列/取消/进度/预估、比较/导出。
3. 模型协议：OpenAI Responses/Chat、Anthropic Messages、Gemini 原生协议，明确参数与支持范围，不将接通当校准。
4. 真实校准工具：冻结协议/种子/场景，独立 pilot/validation，受控替换/档位/截断/混合，完整分母与区间。真实采样与官方基线实测另行提供 Key/预算并授权。
5. 桌面/CLI/SDK/文档/贡献规范/离线 CI 与 Windows 候选构建；真实原生界面/模型校准门槛只据实际证据更新。

## 关键边界

- 业务、探针、参考用量以及官方登录/中转/未知来源继续分开；官方登录不检测。
- 名称/地址/设置仅保存到专用私有配置；Key 默认不保存，可显式保存本程序 UUID 命名空间下的一项系统凭据，不枚举系统凭据、不明文回退。匿名结果与分享文件不包含配置。
- 队列与重启都不自动恢复付费工作。请求数、预估token和失败请求沿用持久预算；未知不记为0。
- 任务版本/模型/协议/参考失配不可比较；旧历史不升级证据。统计偏离不认证身份，不生成真假总分。
- 所有API适配使用专用Key、固定官方参考域名、无代理继承/重定向；业务内容与原始响应不持久化。
- 无外部代码或非商业数据拷贝，不运行模型生成代码，不自动下载插件/评测依赖。
