# Codex 本地用量查看器

[English](README.md) | [简体中文](README-Simplified_Chinese.md)

**当前版本：0.1.0，初始实现，尚未在 GitHub 发布。**

这是独立开发的项目，不是 OpenAI 官方产品，也不代表 OpenAI。界面目前为简体中文；双语 README 仅表示提供双语说明，不表示界面支持语言切换。

## 环境要求

- 主要支持和验证环境为 Windows；双击入口和桌面安装版本识别是 Windows 专用功能，其他平台尚未验证。
- Python 3.11+；已有验证使用 Windows / Python 3.12 和 3.15。
- 本机浏览器和已有 Codex 数据。仅开发时的前端测试需要 Node.js，无须 npm 包。

双击 **`查看Codex用量.cmd`**，自动扫描本机 Codex 数据并打开可交互的本地网页。静态离线采集使用 Python 标准库；交互导出需要本机已有的文档依赖，默认不访问互联网。可选的 `--sync-official` 通过已安装的官方客户端联网读取账号用量与额度，不上传本地日志。需要本机 Python 3.11+，Windows 自带浏览器即可查看报告。

## 使用

1. 保留整个项目文件夹，双击 `查看Codex用量.cmd`。
2. 交互页面从 `.reports/snapshot-*/` 的完整批次提供文件；保持启动窗口打开，点击“更新数据”刷新。普通 CLI 的 `.reports/latest.html` 仍可离线重复打开。
3. 用页面筛选器选择日期、模型、推理强度、项目和会话创建者；会话列表可下钻单轮记录。导出的 CSV 也只在本机生成。
4. 页面“数据来源”提供匿名来源编号、本地查看指引和行号，不嵌入真实路径。自行打开本次选择的数据目录（默认用户主目录中的 `.codex`），按时间定位日志，再按行号核对。不要手动修改 Codex 原文件。

在项目根目录打开 PowerShell 后执行：

```powershell
python -I -S -B .\run.py
python -I -S -B .\run.py --codex-home 'D:\LocalCodexData' --output 'D:\LocalReports'
python -I -S -B .\run.py --json
python -B -m unittest discover -s tests -v
node .\tests\test_dashboard.cjs
```

优先使用 `--codex-home`，其次 `CODEX_HOME` 环境变量，最后默认 `%USERPROFILE%\.codex`。默认输出位置是 `run.py` 同目录的 `.reports/`。输出目录的父目录应已存在，输出目录与受保护的数据或安装目录不能相互包含。网络映射盘、UNC、符号链接和 Windows 重解析点不支持。

| 参数 | 用途 |
| --- | --- |
| `--codex-home PATH` | 指定其他本机 Codex 数据目录 |
| `--output PATH` | 指定独立的报告目录 |
| `--sync-official` | 显式同步官方账号用量与额度；需要 Windows Store 版 Codex 和可读取的 ChatGPT 文件登录 |
| `--json` | 额外生成 `usage.json`，与 HTML 使用相同隐私过滤；仍仅供本地使用 |
| `--show-api-key` | 仅显示本地查看指引，不再打印 API Key 或任何片段 |
| `--help` | 显示命令帮助 |

只采集而不打开浏览器时，直接运行 `run.py`，或运行 `查看Codex用量.cmd --no-open`；`--no-open` 是启动脚本参数，不是 Python 参数。

## 能看到什么

- 账号身份、凭据与私人配置的本地查看指引；默认模型和推理强度。会话、轮次、项目及来源使用报告内的匿名编号，不保存原值对照表。
- Windows 已安装桌面应用版本、本地模型缓存记录的客户端版本、会话中观察到的 CLI 版本及来源。它们是不同版本概念，不会混为一谈，也不检查线上更新。
- 输入、缓存输入、输出、推理输出、总 Token；按日期、项目、会话、单轮、模型和推理强度筛选与统计。
- 本地保存的用量窗口快照：例如 5 小时、每周限额的剩余百分比、重置时间，以及实际记录过的 credits、plan_type 等字段。保留历史、时间和来源，过期快照明确提示。
- 模型缓存里实际列出的型号、推理级别和上下文窗口。**上下文窗口不是账号总额度**。
- 统计覆盖范围、数据库中存在但用量日志缺失的会话数量、损坏/不完整日志提示、每条记录的数据来源。

凭据原文及其片段均不进入报告或终端。下面命令仅显示本地查看指引；需要查看原文时，请自行打开数据目录中的 `auth.json` / `config.toml` 或使用官方客户端管理凭据：

```powershell
python -I -S -B .\run.py --show-api-key
```

系统凭据库、命令型凭据提供器、远程主机和 WSL 内部文件不自动读取；不会为此执行认证命令。

## 统计边界

**本地日志总量不等于当前账号的官方账单总量。** 其他设备、未同步/已删除日志、API 服务商的服务端记录不会凭空补齐。`creator_account_id` 只能证明会话创建者；同会话切换账号后，每轮实际计费归属不能据此保证。

新格式按 `token_usage_record` 的响应 ID 去重；旧格式根据 `token_count` 累计计数的增量统计，处理重复、分叉历史与重置。不会把两种同时出现的格式、数据库 `tokens_used` 和 JSONL 统计重复相加。工具执行和中间回复归入对应用户轮次；子代理保留自己的记录与模型来源。

`cached_input_tokens` 属于 `input_tokens` 的子集，`reasoning_output_tokens` 属于 `output_tokens` 的子集。合计不重复加它们。统计按日志实际返回的数字呈现，不把推理强度换算成费用。

5 小时/每周限制是服务端窗口的用量比例，不能反推出固定 Token 总配额。离线模式下无法获取实时 Settings → Usage & Billing、完整订阅状态、付款方式、发票、API 余额/费用、未记录的单模型额度，也不能用旧快照推断今天仍剩多少。缺失的字段明确显示不可得，不伪造价格或额度。

详细字段和核对方法见 [数据来源说明](../docs/DATA_SOURCES.md)。

## 隐私与只读措施

- 原始配置、登录信息、JSONL 和数据库只读；只写入独立的报告目录。SQLite 原库**不直接连接**：只读复制数据库及 WAL/SHM 到报告目录，读取副本后清理副本。
- 采集进程安装 Python audit hook，拒绝 Python 网络 socket、DNS、HTTP、任意子进程与报告目录外的写入，SQLite 只允许只读连接副本。官方同步模式仅放行一次预配置的官方 stdio 子进程；该原生客户端是独立的信任边界。交互入口另行启动仅本机监听的服务和固定采集工作进程。
- 为防止间接读写，还拒绝 Windows 重解析点（含目录联接与云文件占位符），并拒绝修改具有多个硬链接的输出文件。
- 静态网页是单文件，CSP 禁止网络连接；交互服务返回的页面仅放行同源更新。没有 CDN、远程字体、遥测或自动更新，脚本使用内容哈希授权。
- [敏感信息严格保密](../SECURITY.md)是首要产品原则。凭据及片段、姓名/邮箱/账号标识、私人 URL 与配置、会话/项目原名与原始 ID、真实路径、对话/工具/日志原文均不进入 HTML（包括内嵌数据）、JSON、CSV 或终端输出，只提供本地查看指引。
- 报告保留匿名分组及用量、模型、时间、额度等统计，仍属于私人本地文件，不得上传或用于公开截图；`.reports/` 已从 Git 排除。
- 上述是本程序的技术边界，不是整台电脑或浏览器的系统防火墙。不会修改 Windows 防火墙或其他应用的联网权限。浏览器自身的后台服务不受本项目控制，但报告没有传出数据的代码或外部资源。

可按报告需要联网，但不得在请求中携带敏感信息；当前实现保持默认离线与可选官方同步，本次未新增通用爬虫。用户已明确允许的唯一凭据传输例外是：必要访问令牌及账号标识仅用于 OpenAI 官方认证，禁止发送至其他目的地或在报告中显示。

若 Codex 正在写入日志，最后一行可能尚未完成，或数据库复制期间发生变化；报告会提示，稍后重新运行即可。程序不会为修复这种情况改动源文件。

## 可选官方账号同步

运行 `python -I -S -B .\run.py --sync-official` 获取官方账号快照，可涵盖服务端已纳入的其他设备用量。页面独立展示官方累计 Token、每日图表和额度进度条，不受本地明细筛选影响，不与本地统计相加。不能承诺与官方 overview / analytics 网页同一时刻逐项相等；官方接口未提供的远端逐轮、逐模型明细仍不可得。缺失字段保持未知，不用“官方减本地”推算其他电脑用量。

同步使用已安装的 Windows Store 版官方 Codex，在隔离临时目录中运行。发送认证前核验安全配置，访问令牌仅经私有标准输入交给官方进程，认证保存在内存；不刷新令牌，不复制原凭据或配置。接口不支持、部分失败和登录失效都有明确状态，本地报告仍可生成。原登录文件保持只读；当前没有手动快照导入功能。完整要求与安全边界见[官方同步说明](../docs/OFFICIAL_SYNC.md)。

## 交互更新与多格式导出

双击启动入口现在打开仅本机可访问的交互服务。保留启动窗口，页面“更新数据”会重新采集并生成整套文件，全部成功后自动刷新页面；失败保留旧快照。需要同时刷新官方账号数据时，运行 `启动交互报告.cmd --sync-official`。默认不访问互联网，已保存的 HTML 仍是静态快照。

格式选择支持 Word/PDF 汇总报告、Excel 完整匿名数据、PNG/JPEG/WebP/SVG 概览图片，以及原有 CSV 筛选明细。新增格式导出整份快照，不跟随页面筛选。每批文件在本地 `snapshot-*` 目录中；成功更新后页面筛选重置。

导出依赖本机已有 python-docx、openpyxl、Pillow、reportlab 及 Windows 微软雅黑字体；启动脚本优先使用已有 Codex 工作区 Python，否则使用 PATH Python，不会下载安装。命令为 `python -I -B run.py --serve` 或 `--all-formats --json`，导出模式勿加 `-S`。普通 CLI 与 `--no-open` 仍保留静态采集。详见[交互报告说明](../docs/INTERACTIVE_REPORTS.md)。
