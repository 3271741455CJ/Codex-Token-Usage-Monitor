# 本机交互报告与多格式导出

双击 `查看Codex用量.cmd` 或 `启动交互报告.cmd`，启动仅监听 `127.0.0.1` 随机端口的本机服务并打开报告。保留启动窗口；关闭窗口停止服务。默认不访问互联网。要让每次更新也同步官方账号用量，运行 `启动交互报告.cmd --sync-official`。仅使用已授权的官方认证方式；不上传日志或报告。

## 格式与范围

- HTML：保留现有交互统计、筛选和下钻。
- Word（report.docx）与 PDF（report.pdf）：整份快照的汇总、官方每日、本地每日、模型和额度窗口；完整明细见 Excel/HTML。
- Excel（records.xlsx）：概览、全部经过隐私过滤的字段、会话、轮次、本地每日和官方每日。文本按字符串保存，不执行公式。空值标记未知。
- PNG、JPEG、WebP、SVG：用量概览图片，不以一张图片强行塞入全部明细。
- CSV：保留原有当前筛选范围内的轮次导出。

网页顶栏选择格式后点击“导出”。新增格式导出整份快照，不受网页筛选影响；CSV 单独标为筛选明细。

## 更新与文件

在本机交互页面点击“更新数据”，重新只读采集、生成整套文件，成功后自动刷新页面。每批文件在输出目录的 `snapshot-*` 子目录内，拥有同一采集时间。只有全部生成成功才切换当前服务的快照；失败保留旧数据，按钮支持重试。旧批次保留本地，可自行清理。固定的下载地址始终指向当前成功批次。新页面刷新会重置筛选条件。

直接双击已经保存的 HTML 仍是静态模式，不能自行启动 Python；更新按钮提供本机交互入口指引。同目录存在配套文件时可离线下载。下载或另存的副本不会自动更新。

## 本机依赖与命令

导出需要 Python 3.11+ 和本机已有的 `python-docx`、`openpyxl`、`Pillow`、`reportlab`，以及 Windows 微软雅黑字体。启动脚本优先使用本机已有 Codex 工作区运行时，否则使用 PATH 中的 Python。程序不下载依赖；依赖缺失时需用户自行准备环境。

```powershell
python -I -B run.py --serve
python -I -B run.py --serve --sync-official
python -I -B run.py --all-formats --json
```

导出模式不要使用 `-S`，它会禁用本机第三方包。普通 `python -I -S -B run.py` 仍只生成静态 HTML；`查看Codex用量.cmd --no-open` 保留原有静态采集行为。

## 保密与服务边界

所有格式在序列化前使用同一隐私过滤：不显示凭据及片段、身份、原始路径/标题/ID、私人配置和原始对话。匿名统计仍属私人数据。服务不记录访问日志，不提供目录列表，不接收文件上传，也不暴露任意文件路径。仅允许固定报告文件路由，校验 Host、随机会话路径；更新要求同源 Origin、专用请求头及空请求体，不启用 CORS。

采集在固定命令启动的独立工作进程中运行，保留源文件只读、SQLite 副本、Python 外网与越界写入限制。仅本机服务进程可以监听回环端口和启动固定采集命令；官方子进程例外保持原有检查。静态 HTML 禁止连接；服务返回的 HTML 仅放行同源连接用于更新。操作系统和其他本机程序仍在信任边界内。
