# 本地数据来源与统计口径

本工具把本机已有记录汇总成离线报告。默认模式不调用 OpenAI、第三方 API 或账单接口。用户显式选择 `--sync-official` 时，通过官方 Codex app-server 补充账号用量与额度快照，独立于本地明细。找不到的字段应显示“本地未提供”或“未知”，而不是 `0`。

## 定位 Codex 数据目录

默认读取环境变量 `CODEX_HOME`；未设置时使用用户主目录下的 `.codex`。Windows 常见路径为 `C:\Users\你的用户名\.codex`。启动时指定其他目录，只会改变读取位置，不会修改 Codex 的配置或登录。

在资源管理器地址栏输入 `%USERPROFILE%\.codex`，即可自行查看默认目录。报告的来源区仅提供匿名编号、本地查看指引和行号，不嵌入实际路径。读取规则只接受本机磁盘，拒绝 UNC 路径、网络映射盘以及符号链接或目录联接。

## 文件与字段

| 文件 | 本地可读取的信息 | 解释与限制 |
| --- | --- | --- |
| `auth.json` | 登录方式、当前缓存的账号 ID、JWT 中的姓名/邮箱/套餐、最近刷新时间 | JWT 仅在本机解码；没有联网验证签名、登录有效性或订阅状态。身份与凭据原文均不输出；报告仅提供本地查看指引。 |
| `config.toml` | 默认模型、推理强度、提供商、Base URL、API Key 配置来源 | 配置默认值不代表每个历史会话的实际模型；会话中存在更具体记录时优先采用记录。Key（包括掩码片段）、私人 Base URL 和配置来源不输出，仅提供本地查看指引。 |
| `models_cache.json` | 已缓存的模型目录、模型显示名、支持的推理档位、上下文窗口、缓存时间、CLI 版本线索 | 缓存可能过期；上下文窗口是单次上下文容量，不是账号总额度。模型存在于缓存不保证当前账号此刻仍可调用。 |
| `sessions\**\*.jsonl` | 活跃/普通会话中的轮次、模型、推理强度、Token 计数、历史限额快照 | 按本地已写入的日志统计；云端其他设备产生或已删除的记录不在覆盖范围内。 |
| `archived_sessions\**\*.jsonl` | 已归档会话的同类记录 | 与普通目录一并去重；归档不应导致重复计数。 |
| `session_index.jsonl` | 会话标题与索引元数据 | 只在本地处理；报告用匿名会话编号替代标题，不是独立 Token 消耗来源。 |
| `state_*.sqlite` | 会话标题、项目、创建者账号、模型/推理强度线索、归档状态与索引计数 | 选择最高编号的存在版本，按实际表结构读取允许字段。`tokens_used` 不与 JSONL 计数相加，避免重复统计。 |
| `state_*.sqlite-wal` / `-shm` | 数据库尚未检查点的更新与共享索引 | 原文件只读复制到报告目录中的临时工作目录；SQLite 只连接临时副本，完成后清理副本。 |
| 本地安装目录/清单 | 已安装桌面程序版本线索 | 必须与模型版本、CLI 版本、缓存记录时的版本分别显示；不会执行更新检查或下载程序。 |

程序不会读取聊天正文来估算 Token，也不会把完整聊天正文、工具参数或工具输出复制进报告。身份、标题、原始 ID、私人配置与路径只用于本地内存中的关联处理；输出前删除或替换为报告内的匿名编号，不保存原值对照表。报告保留模型、时间、用量、额度和行号等统计，仍仅供本人本机查看。

## Token 的含义

输入 Token 包含缓存输入，输出 Token 包含推理输出。这两个子集不应再次累加。常见公式为：

`总 Token = 输入 Token + 输出 Token`

`非缓存输入 Token = 输入 Token - 缓存输入 Token`

单次“用户一问、Codex 一答”可能触发多次模型调用及工具循环。报告以可识别轮次聚合这些事件，模型和推理档位应来自对应轮次记录。工具调用数不等于模型请求数；日志事件数也不等于模型调用数。只有来源确实记录了请求边界时才能给出精确的模型调用次数。

新格式优先按 `token_usage_record` 的响应 ID 去重并分配到轮次；旧格式使用相邻累计计数的差值。两种格式同时出现时不能重复相加；重复快照、复制会话及分叉历史需要去重。若计数重置、日志截断、缺少轮次或缺少模型字段，报告保留相应覆盖说明，不把推断值当作精确账单。

## 账号归属

`auth.json` 说明本次扫描时缓存的登录身份。它不能证明历史全部记录都属于该账号。

数据库中 `threads.creator_account_id` 可说明会话创建者账号。它仍不能证明随后每一次请求都使用同一登录身份，因此创建者匹配与每轮账单归属是不同概念。没有账号证据的记录显示“归属未知”，可以单独筛选。切换账号、复制数据目录、多设备以及云端会话都会影响覆盖范围。

## 限额与账单

JSONL 的 `rate_limits` 是请求发生时记录的历史快照。窗口已用百分比、窗口长度、重置时间、套餐或 credits 等，只在原记录提供时展示。每项必须标记记录时间及来源，并说明已过期或刷新时间未知。某个模型只有共享额度池时，不虚构单独额度。

剩余百分比可以按 `100 - 已用百分比` 展示，并限制在 0–100% 范围。百分比不能换算成 Token 总额度，也不能据此计算套餐实际费用。5 小时、每周窗口会受到服务端策略影响；离线报告不能刷新服务端计数。原始数值异常时保留诊断说明。

默认离线模式只能读取 Settings → Usage & Billing 中已经在本地持久化的部分数据。付款方式、发票、订单、实时余额、完整云端用量及未缓存的限额不会因离线扫描自动出现。默认离线模式不会获取这些字段；可选官方同步只读取已公开的账号用量及额度字段，不获取付款方式或发票，也不保证完整远端明细。

## 自行核对来源

1. 在报告“来源”区查看本地指引、匿名来源编号及行号/表名。
2. 自行用资源管理器打开本次选择的 Codex 数据目录（默认用户主目录中的 `.codex`），按会话时间定位文件。JSONL 可用文本编辑器按行号检查，只需查看 `token_usage_record`（逐响应用量）、`token_count`（累计快照）、`turn_context`、`task_started`、`task_complete` 等结构化事件。单轮弹窗的“用量事件来源”列出了实际参与统计的每条事件。
3. SQLite 数据源需要同时考虑同名 `-wal` 文件。请复制数据库及 sidecar 到单独目录，再使用自己信任的 SQLite 查看工具打开副本；不要对正在使用的原数据库执行写入或维护操作。
4. 重新运行启动入口即可更新本地统计；仅刷新已生成的 HTML 不会重新读取 Codex 原始文件。

不要把 `auth.json` 原文、API Key、原始会话日志或生成的私人报告发到公开网站。该说明不要求联网安装任何工具。

## 联网许可与只读边界

首要规则见 [SECURITY.md](../SECURITY.md)：允许按报告需要联网，但敏感信息不得外传；仅必要凭据和账号标识可按用户授权用于 OpenAI 官方认证。当前没有通用爬虫；保留默认离线和可选官方同步。

采集工作进程为本次采集安装审计钩子，拒绝网络套接字、联网库事件及任意子进程，写入限制在独立输出目录。可选官方同步仅允许启动一次精确配置的官方 stdio 子进程，由其联网查询；详情见[官方同步说明](OFFICIAL_SYNC.md)。静态 HTML 采用限制性 CSP，禁用网络连接与外部资源。本机交互页面仅允许同源刷新，服务边界见[交互报告](INTERACTIVE_REPORTS.md)。源目录不设置写权限；默认离线模式不运行 Codex 命令。官方同步使用独立临时目录和内存认证，原始源文件不交给子进程。

这些约束针对本项目自己的代码路径，并非操作系统级防火墙，不能控制浏览器扩展、用户另行安装的软件或同时运行的 Codex 客户端自身行为。源文件可能被 Codex 正常写入；工具通过快照/重试报告扫描期间的变化，不能承诺跨所有文件的同一时刻事务快照。
