    如何核对与更新

    1. 在“历史明细”中点开会话或某一轮，查看来源编号、行号和本地查看指引。
    2. 自行打开本次选择的 Codex 数据目录（默认用户主目录中的 .codex），按时间定位 sessions / archived_sessions 中的日志，再按行号核对 token_usage_record 或 token_count 事件。
    3. 输入 / 缓存 / 输出 / 推理各自读取对应字段；累积快照以相邻记录的差值统计，不能把所有累积快照直接相加。
    4. 再次双击项目的启动入口可重新扫描并生成报告。浏览器刷新当前页面只重新载入已生成的快照。
    5. 会话、项目和来源使用本报告内的匿名编号，不保存原值对照表。报告与 CSV 仍包含私人使用统计，请仅在本机保管。
